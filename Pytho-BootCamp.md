Working with VS Code we can actually use different languages ( it was not built only for Python )
So for that we need to create a virtual Environment so that the VSCode will know that this is a python env and it will contain many libraries that are
python related.

first make sure you have anaconda installed ( it is a package manager that helps configure and install all you need for your project )
Anaconda is a Python ( but not only python ) distribution that includes everything needed for scientific computing, data analysis, and machine learning.

Execute via the VSCode terminal:

`conda create -p venv python=3.12`   --> this will install mandatory packages for your python project

once done execute `conda activate venv`

venv is a virtual env directory that will automatically be created on your VSCode and will be used to run your python environment
